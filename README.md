# KHELLOK

A home for Indian games and interactive experiences.

## Games

- [YudhKala Boxing](./yudhkala/boxing/) — first playable browser boxing prototype (player versus CPU). Two fighters share a temporary character model until a distinct opponent is approved.

The YudhKala Boxing code and 3D assets are placed in `yudhkala/boxing/`. This repository is in early development; do not treat the prototype as production-ready.
